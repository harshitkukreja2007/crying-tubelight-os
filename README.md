# crying-tubelight-os


A cybersecurity-hardened smart tubelight running TubeLite OS.

It supports:
- MFA authentication
- simulated hacking attacks
- firewall monitoring
- emotional JavaScript breakdowns
- terminal-based exploits
- emergency recovery systems

Unfortunately, it also cries.


## Features

- Retro cyberpunk terminal UI
- Fake Linux terminal commands
- Multi-Factor Authentication (MFA)
- 3-stage hacking simulation
- Firewall integrity system
- Emotional exception logging
- Emergency recovery patching
- Interactive animations and effects



## Control Panel Buttons

### POWER ON/OFF
Turns the light on/off.

If MFA is enabled:
PIN = `1234`

### TRIGGER BREAKDOWN
Forces the tubelight to throw emotional JavaScript errors and cry.

### TOGGLE MFA
Enables/disables Multi-Factor Authentication.

### EMERGENCY PATCH
Repairs the firewall and restores the system.

### LEAVE UNATTENDED
Slowly degrades the firewall until collapse.

### PURGE LOGS
Clears the emotional exception logs.
